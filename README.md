# Development

## Using Docker
1) Run `docker compose up --build`
2) Go to `http://localhost:5173` for the frontend
3) Go to `http://localhost:8080` for the backend API

### Running the frontend
1) Make sure you have Node >=24.12.0 installed on your machine
2) Navigate to `/frontend`
3) Run `npm install`
4) Run the dev server on `npm run dev` available at `http://localhost:5173`
